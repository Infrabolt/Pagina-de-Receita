# Pagina-de-Receita
Este repositório contém uma página web simples, construída com HTML e CSS puro, que apresenta uma deliciosa receita de bolo. Acesse a receita passo a passo, com ingredientes e instruções claras, ideal para iniciantes e amantes da culinária. Aprenda a fazer um bolo irresistível e surpreenda seus amigos e familiares com suas habilidades na cozinha!
